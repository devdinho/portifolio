# Portfólio — Anderson Freitas

Portfólio pessoal com experiência profissional, projetos e competências técnicas.

**Stack:** React, TypeScript e Vite.

## Rodar localmente

```bash
npm install
npm run dev
```

## Build

```bash
npm run build     # gera dist/
npm run preview   # serve o build localmente
```

## Onde editar o conteúdo

| Arquivo | Conteúdo |
| --- | --- |
| `src/components/WorkExperience.tsx` | Contatos, experiências (`experiences`) e projetos (`projects`) |
| `src/components/Skills.tsx` | Categorias de competências |
| `src/constants/roles.tsx` | Cargos que aparecem em rotação no topo |
